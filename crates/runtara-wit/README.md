# runtara-wit

Canonical WIT contracts of every runtara component, in one place.

Packages are grouped by who may import them, so each package is one privilege
class and one versioning cadence:

| Package | Imported / exported by |
|---|---|
| `runtara:agent` | every component (`types`); suspending agents (`continuation`) |
| `runtara:host` | ordinary agents and workflows (`http`, `sql`, `connections`, `timers`) |
| `runtara:workflow` | compiled workflow logic only |
| `runtara:workflow-stdlib` | the compiler-private JSON stdlib component |
| `runtara:trusted` | approved trusted agents only |
| `runtara:control` | the control agent only |

Each agent also exports its own `runtara:agent-<id>` package, generated by
`agent_package`, so composition can tell agents apart.

## Using it

- **Names:** use the constants (`runtara_wit::host::HTTP`,
  `runtara_wit::workflow::RUNTIME`, …) instead of string literals.
- **Guest bindings:** point `wit_bindgen::generate!` at `wit/<package>`
  directories; proc macros use `runtara_wit::WIT_DIR` for absolute paths.
- **Compiler and tests:** `resolve()` (feature `resolve`) returns one
  `wit_parser::Resolve` holding every package, in dependency order.

## Versioning

Released WIT is never edited, only versioned. An additive change (a new
function or interface) bumps the package minor version, and the host links only
the newest minor. Any change to an existing function or type bumps the major
version, and the host keeps linking the old major until no parked run needs it.

## Tests

```bash
cargo test -p runtara-wit --features resolve
```
